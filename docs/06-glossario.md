# 06 — Glossario

| Termine | Significato |
|---|---|
| **PHA** — Process Hazard Analysis | Analisi sistematica dei pericoli di un processo; obbligatoria per OSHA PSM e utile per Seveso |
| **HAZOP** — Hazard and Operability Study | Tecnica PHA a guideword applicate a nodi (IEC 61882) |
| **Nodo** | Porzione di impianto con intento progettuale definito, analizzata come unità |
| **Intento progettuale** | Cosa il nodo deve fare (es. "trasferire 20 m³/h di nafta a 5 barg, 40 °C") |
| **Guideword** | Parola guida: NO, PIÙ, MENO, INVERSO, ANCHE, PARTE DI, ALTRO DA… |
| **Parametro** | Grandezza di processo: flusso, pressione, temperatura, livello… |
| **Deviazione** | Guideword + parametro (es. "Più temperatura") |
| **Causa** | Evento che può originare la deviazione |
| **Conseguenza** | Esito della deviazione se nessuna protezione funziona |
| **Salvaguardia** (Safeguard) | Misura esistente che previene o mitiga |
| **Raccomandazione** | Azione proposta dal team per ridurre il rischio |
| **Matrice di rischio / Criticality matrix** | Griglia severità × probabilità che assegna un livello di rischio |
| **ALARP** | As Low As Reasonably Practicable |
| **What-If** | Brainstorming strutturato a domande "Cosa succede se…" |
| **Checklist** | Verifica rispetto a elenchi di buone pratiche |
| **FMEA / FMECA** | Failure Mode and Effects (and Criticality) Analysis |
| **RPN** | Risk Priority Number = S × O × D |
| **HAZID** | Hazard Identification, tipica delle fasi iniziali di progetto |
| **LOPA** | Layer of Protection Analysis, analisi semi-quantitativa a strati di protezione |
| **Evento iniziatore (IE)** | Causa dello scenario LOPA, con frequenza (/anno) |
| **Modificatore abilitante / condizionale** | Probabilità che riducono la frequenza (presenza, accensione, esposizione) |
| **IPL** — Independent Protection Layer | Protezione indipendente, efficace e verificabile |
| **PFD** — Probability of Failure on Demand | Probabilità che l'IPL fallisca quando chiamato |
| **TMEL** | Target Mitigated Event Likelihood: frequenza tollerabile |
| **MEF** | Mitigated Event Frequency: frequenza dopo gli IPL |
| **RRF** | Risk Reduction Factor = 1/PFD |
| **SIF / SIS / SIL** | Safety Instrumented Function / System / Safety Integrity Level (IEC 61511) |
| **SRS** | Safety Requirements Specification |
| **BPCS** | Basic Process Control System (DCS) |
| **PSV** | Pressure Safety Valve (valvola di sicurezza) |
| **P&ID / PFD (disegno)** | Piping & Instrumentation Diagram / Process Flow Diagram |
| **Bow-tie** | Diagramma minacce → top event → conseguenze con barriere |
| **PSM** | Process Safety Management (OSHA 29 CFR 1910.119) |
| **RMP** | Risk Management Program (EPA 40 CFR 68) |
| **MOC** | Management of Change |
| **Revalidation** | Riesame periodico (tipicamente ogni 5 anni) di una PHA |
| **Parking lot** | Elenco di questioni rinviate durante la sessione |
| **Release** | Revisione congelata e firmata di uno studio |
| **Mirroring** | Dato mostrato in più fogli ma memorizzato una volta sola |
| **AutoType** | Completamento automatico da testi già usati/librerie |
| **Keyword** | Identificativo di un livello della gerarchia del template |
| **Workspace** | Pannello di navigazione con studi aperti e librerie attive |
| **Librerie attive** | Librerie abilitate per lo studio; alimentano AutoType e Copy From |
| **Diagramma collegato** (Linked Diagram) | Schema a blocchi disegnato nel programma, con forme legate ai nodi |
| **Risk System** | Insieme di scale, codici, matrice e colori collegato a un livello della gerarchia |
| **Breakdown** | Raggruppamento delle righe di un foglio per una colonna |
| **Report Collection** | Insieme salvato e ordinato di fogli/report da pubblicare insieme |
| **Data Check** | Controllo di completezza e coerenza dei dati prima dell'approvazione |
| **Change Log / Revision Chain** | Registro delle modifiche / catena delle release di uno studio |
| **Data Dictionary** | Vocabolario controllato di codici e categorie condiviso fra template |
| **Risk Graph** | Metodo a grafo (C, F, P, W) per determinare il SIL (IEC 61511-3) |
| **Safety Layer Matrix** | Matrice per determinare il SIL dagli strati di protezione esistenti |
| **CHAZOP / HACCP / DHA / SIMOPS** | HAZOP dei sistemi di controllo / analisi dei punti critici alimentari / analisi pericoli da polveri / operazioni simultanee |
